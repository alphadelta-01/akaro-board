# akaro-board
Проект, имеющий минимальный функционал, схожий с функционалом старых кнопочных телефонов.

## 🛠️ Комплектующие (Hardware)
- **ESP32-C3 SUPERMINI** - мозги нашего проекта.
- **OLED 0.96" I2C** - экран.
- **4 кнопки** - управление (Вверх, Вниз, Влево, Вправо).
- **АКБ 3.7В** - питание (Li-Ion).
- **TP4056** - плата зарядки для АКБ.
- **3-х контактный переключатель** - для полного отключения питания.
